# EventX Mobile

A gift/"moi" collection-tracker app — create events, record who gave and received what, and keep a running ledger per event. Built as a single-page HTML/CSS/JS app in [www/index.html](www/index.html), wrapped with [Capacitor](https://capacitorjs.com) to ship as an Android app.

## Run in a browser (fastest way to iterate)
```bash
npm install
npm run serve
```
Open http://localhost:5173. Any login works (demo auth, no backend). Data (events + gift records) persists in `localStorage`.

## Demo flow
Login/OTP → My Events → Create/Open Event → event details → Send/Receive → gift entry form → View Records (live ledger with quick filters, search, and running totals).

## Build the real Android APK

The Capacitor Android project already exists at [android/](android/) (added via `npx cap add android`). Compiling it needs a JDK and the Android SDK, which aren't installed on this machine yet. One-time setup:

1. Install **Android Studio** (https://developer.android.com/studio) — it bundles a JDK and the Android SDK, and is the smoothest path since it also gives you an emulator.
2. Open this project's `android/` folder in Android Studio once, so it can finish the Gradle sync and let you accept the SDK license through its UI.
3. From then on, either build from Android Studio directly (Build → Build APK(s)), or from the command line:
   ```bash
   npm run cap:sync    # copies www/ into the Android project's assets
   npm run cap:build    # runs ./gradlew assembleDebug
   ```
   The debug APK lands at `android/app/build/outputs/apk/debug/app-debug.apk` — sideload it onto a phone, or drag it onto a running emulator.

Whenever you change files in `www/`, run `npm run cap:sync` before rebuilding the APK so the native project picks up the changes.

## Project layout
- `www/` — the actual web app (HTML/CSS/JS), and the Capacitor `webDir`
- `android/` — native Android/Gradle project generated by Capacitor
- `capacitor.config.json` — app id (`com.eventx.app`), app name, web dir
- `requierment files/` — source mockups and specs the design is built from
